# 野生捕获动画封包

客户端使用 S2C `0x37` 播放精灵球抛掷、摇晃和结果动画。服务端不使用普通道具动作 S2C `0x39`。

## 封包

```text
flow: SERVER_TO_CLIENT
opcode: 0x37 (十进制 55)
```

| 偏移 | 长度 | 字段 | 说明 |
| ---: | ---: | --- | --- |
| `0x00` | 1 | 战斗选择器 | `debutFactionIndex | (debutIndex << 4)`，定位播放动画的战斗宝可梦 |
| `0x01` | 2 | 精灵球道具 ID | little-endian，道具索引 ID |
| `0x03` | 1 | 捕获结果 | `0/1/3` 失败摇晃次数，`4` 成功 |
| `0x04` | 1 | 容器类型 | 仅成功结果；`0=PC`、`1=PARTY` |
| `0x05` | 2 | 槽位 | little-endian，仅成功结果 |

客户端服务端方向的 `sv_1` 按上述顺序读取；客户端发往服务端的同 opcode `sn_2` 是另一条方向消息，
只携带选择器和结果，不能用来定义 S2C 布局。第五世代普通捕获使用三次判定，因此服务端不会发送结果 `2`。
临界捕获只进行一次判定，失败为 `1`（一次摇晃），成功为 `4`。成功结果附带客户端需要的 PARTY/PC 容器和槽位。

示例：

```text
失败、1 次摇晃（选择器 `0x10`、精灵球道具 `0x138C`）: `37 10 8C 13 01`
成功（选择器 `0x10`、精灵球道具 `0x138C`、PARTY 槽位 `0`）: `37 10 8C 13 04 01 00 00`
```

捕获结果由 `Gen5CaptureCalculator` 生成，概率输入包括物种捕获率、当前 HP、异常状态、球种效果、
战斗回合、场地和图鉴临界捕获概率。动画包发送后再同步球数量（S2C `0x41` 或 `0x43`）。
第五世代的巢穴球使用 `floor((41 - level) * 4096 / 10) / 4096`（等级 `30+` 为 `1x`），计时球使用
`1 + turns * 1229 / 4096`，潜水球在冲浪、潜水或钓鱼遭遇中使用 `3.5x`，黑暗球在洞窟中使用 `3.5x`；
服务器尚未接入昼夜和钓鱼封包时，不伪造未验证的环境加成。
