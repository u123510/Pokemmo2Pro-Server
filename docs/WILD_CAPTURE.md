# 野生宝可梦捕获

野生战斗使用 C2S `0x32` 的 `BattlePokemonCommandPacket`。球类的
`itemTargetId = 0` 表示敌方当前宝可梦。结算链路为：

```text
C2S 0x32
  -> BattleRoundSettlement.useItemSettlement()
  -> BattleCaptureService
  -> Gen5CaptureCalculator
  -> PokemonCaptureService
```

## 第五世代判定

服务端使用 `resource/pokemon/CaptureSpecies.jsonc` 中的种族捕获率，并按
第五世代公式计算：

```text
G = dark-grass modifier (only in dark grass)
R = catchRate + heavyBallModifier
X = down(round(down(round((3 * maxHp - 2 * currentHp) * G) * R * B)
          / (3 * maxHp)) * S * E / 100)
Y = floor(65536 * (X / 1044480) ^ 0.25)
```

`G`、`B`、`S`、`E` 和 `X` 使用第五世代 `1/4096` 定点整数；普通野外战斗的
Entralink 捕获力 `E` 固定为 `100`。先对
`(3 * maxHp - 2 * currentHp) * G` 做一次最近值舍入，再完成捕获率、球倍率和 HP 除法；状态倍率
阶段再次按最近值舍入，最后按 `down` 完成 `X`。`Y` 是最终的
`0..65536` 摇晃阈值；
睡眠/冰冻状态倍率为 `2.5`，中毒/剧毒/灼伤/麻痹为 `1.5`，其他状态为 `1`。
内部 `a` 的上限为 `255 * 4096 = 1044480`，达到上限直接成功；否则
普通捕获进行三次 `0..65535` 判定，三次全部通过才成功。
第五世代临界捕获先按已捕获图鉴数量取 `P = 0/0.5/1/1.5/2/2.5`，再计算
`floor(min(255, X) * P / 6)`，与 `0..255` 随机值比较；临界捕获只进行一次判定。

正常失败动画结果严格使用 `0`、`1` 或 `3`，避免客户端出现错误的“两次摇晃”；成功为 `4`。

## 球种效果

`resource/item/CaptureBall.jsonc` 只配置可选的通用倍率覆盖；默认效果由
`Gen5CaptureCalculator` 实现。包括大师球必定成功、超级球/高级球、狩猎球、捕网球、潜水球、
巢穴球（第五世代 `floor((41 - level) * 4096 / 10) / 4096`，等级 30 仍为约 `1.1x`，等级 31 起为 `1x`）、重复球、计时球、黑暗球、先机球、竞赛球、速度球、等级球、
诱饵球、沉重球、甜蜜球、月亮球，以及友友球、治愈球、豪华球的附加效果。梦境球在未接入
梦境世界场景时按普通球处理，不伪造场景专属加成。

固定基础倍率为：精灵球/豪华球/纪念球/治愈球/贵重球/友友球/梦境球 `1x`，超级球 `1.5x`，
高级球 `2x`，狩猎球与竞赛球 `1.5x`。条件球由战斗状态覆盖基础倍率：捕网球虫/水属性 `3x`，
潜水球水上/潜水/钓鱼 `3.5x`，重复球已捕获物种 `3x`，黑暗球洞窟或室外夜晚 `3.5x`，
先机球首回合 `5x`，速度球基础速度至少 `100` 时 `4x`，等级球 `1/2/4/8x`，诱饵球钓鱼 `3x`，
甜蜜球同种异性 `8x`，月亮球可用月之石进化时 `4x`。计时球为
`min(4, 1 + turns * 1229 / 4096)`；沉重球修改种族捕获率而不是球倍率。

当前野外遭遇链路可以识别洞窟、冲浪与潜水环境；计算器也保留夜晚和钓鱼输入。昼夜状态与钓鱼
请求尚未进入战斗上下文，因此现阶段不会把普通室外战斗误判为夜晚，也不会伪造诱饵球的钓鱼加成。

## 捕获持久化

`PokemonCaptureService` 在事务中锁定主背包球堆叠并扣除一个；成功时优先写 PARTY 空槽，否则写 PC，
设置捕获球、第五世代基础亲密度、友友球 `200`、治愈球满 HP/正常状态，并更新
`pokemon_dex.caught_level`。失败时只扣球，战斗继续。

每次已扣球尝试先发送 S2C `0x37` 捕获动画，再发送 S2C `0x41` 更新剩余数量或 S2C `0x43` 删除空堆叠。
`0x37` 携带战斗选择器、球道具 ID 和动画结果；成功时还携带容器与槽位，字段见
[`BATTLE_CAPTURE_PACKET.md`](BATTLE_CAPTURE_PACKET.md)。
