# 战斗伤害机制

`org.pokemmo.gameserver.game.battle.BattleDamageCalculator` 负责物理和特殊招式的伤害结算，
由 `BattleMoveResolver` 在命中后调用。公式以第五世代为基础，并沿用项目已有的战斗属性、
性格、道具、特性和能力阶级计算：

```text
base = floor(floor(floor((2 * level + 10) / 5) * power * attack / defense) / 50) + 2
damage = base * targets * weather * critical * random * STAB * type * other
```

基础值之后的倍率按项目协议约定逐步取整：四舍五入到最近整数，恰好 `x.5` 时向下取整；属性免疫直接返回
`0`，普通伤害在属性倍率后至少为 `1` 点，但多重鳞片等小于 `1` 的最终减伤仍可能把结果降为 `0`。

当前实现覆盖等级、招式威力、物理/特殊有效攻防、`PokemonNatureType` 的 1.1/0.9 修正、
0.75 多目标、雨天/晴天、暴击、85..100 随机数、STAB（适应力为 2 倍）、属性相性、烧伤/毅力、
厚脂肪、干燥皮肤、过滤/坚硬岩石、多重鳞片、神奇守护、破格、胆量以及无关天气/气闸。

项目资源中标记为 `isTrueDamage` 且已确认的招式按固定伤害处理，不使用天气、STAB 或暴击倍率，
但仍检查招式属性带来的免疫（例如幽灵属性免疫普通/格斗招式）；非免疫目标不应用属性相性倍率。
当前已确认固定伤害招式包括断头钳、角钻、音爆、双倍奉还、地球上投、龙之怒、地裂、黑夜魔影、
精神波、愤怒门牙、镜面反射、蛮干、绝对零度、金属爆炸和搏命（资源 ID `12/32/49/68/69/82/90/101/149/162/243/283/329/368/515`）。
未确认的特殊招式仍按资源中的 `isTrueDamage` 与基础威力走统一公式。招式专属威力、道具增伤、
场地减伤和状态持续伤害尚未全部从资源字段映射，属于后续扩展项。

命中失败只产生 `MISS` 结果，不会继续扣除目标 HP；无效或零伤害命中会清空本回合的上一笔伤害记录，
避免 `Counter`、`Mirror Coat` 等招式错误反射旧伤害。HP 变化仍通过现有的
`BattlePokemonRemainHpEffect` 广播，击败野生宝可梦的经验结算路径保持不变。
