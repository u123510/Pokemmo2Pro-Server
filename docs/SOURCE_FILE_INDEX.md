## server.game

文件数量：687。Java（含 18 个 JUnit 测试文件）+ resources + 模块配置。

真新镇剧情改造移除了旧 interact/event 的 39 个剧情资源、旧地图/角色硬编码分支、
`InteractManager.runScript` 及全注释 `ScriptSession`。新编排位于 `game.story`，
事务位于 `services.story`，不删除玩家数据；详见 [剧情与存档](PALLET_TOWN_STORY.md)。
后续包裹/图鉴章由 `StoryService` 路由到 `OakParcelStory`，资产和阶段由
`OakParcelStore` / `StoryInventory` 原子保存；详见 [大木包裹章](OAK_PARCEL_STORY.md)。
`PalletStoryBattle` 的初始化编码检查、失败清理及跨客户端 `f.iv_1` 的协议修复见
[战斗初始化](BATTLE_INIT_PACKET.md)；`PalletStoryTest` 增加对应字段和失败路径回归源码。
部分重置冲突由现有 `PalletStoryProgress` 统一校验，`PalletOpeningService` 在剧情锁定前调用，
`PalletStoryStore` 在事务中复核；`PalletStoryTest` 新增两条回归源码，不新增 Java 文件。
具体字段和处理方式见 [阶段不一致报错](PALLET_TOWN_STORY.md#阶段不一致报错)。

场景交互由 `game.interact` 的 `SceneInteractionService` 识别 NPC/电脑/未知目标，
`PcInteractionService` 管理电脑菜单；C2S `EmptyInteractPacket`/`StartTalkPacket` 只负责
请求校验与分派，`InteractPacket` 转交 PC 选项。`MapFile` 保留 NPC 脚本键到
`NpcEntity.interactionScriptName`。协议与限制见 [场景交互](PC_INTERACTION_PACKET.md)。
`game.shop` 负责独立店铺配置、`npcs` 直接指定 NPC、兼容旧地图 `shopId`、
绑定与价格快照、报价和在线同步，`ShopNpcBinding` / `ShopNpcBindings` 负责绑定模型与目标校验索引，
`services.shop` 负责带 owner 条件的购买/出售事务。`SendItemShopPacket` /
`ShopControlPacket` / `SendShopControlPacket` 负责原生窗口和协商扩展；
`ReloadShopsCommand` 一起重载绑定和价格，角色/地图/连接生命周期清理报价。
柜台元数据由 `OpenMmoMapConfig` / `OpenMmoMapDataReader` 加载。
详见 [NPC 商店](NPC_SHOP_PACKET.md)及[客户端修改方案](NPC_SHOP_CLIENT_INTEGRATION.md)。

`SpawnNpcCommand` / `NpcSpawnRequest` / `NpcSpawnService` 负责客户端 NPC Tool 的生成命令，
先经 `game.npc` 的定义/编解码/原子存储/目录组件保存到独立 `resource/npc/custom`，
再用 `MapData` 的新增字典发布和 GBA/NDS 的编号初始化，复用 S2C `0x12`。
`ScriptManager` 启动时先恢复自定义 NPC 再加载商店。原地图文件不变，
完整记录见 [NPC 生成与独立保存](CHAT_SPAWNNPC_COMMAND.md)。

`EventDeleteNpcCommand` / `NpcDeleteService` 先持久化停用再移除在线自定义实体；
`NpcVisibilityService` 共用生成和地图快照发送，`ShopCatalog` / `ShopSessions`
负责与成交互斥及关闭相关报价。详见 [NPC 删除](CHAT_EVENTDELETENPC_COMMAND.md)。

`EventSpawnNpcCommand` / `EventNpcSpawnRequest` 严格接入原事件工具参数，
`NpcSpawnAppearance` 投影视觉参数；独立 NPC 文件版本 2 保存分类/闪光/缩放，
保留版本 1 兼容，详情见 [事件 NPC 手动生成](CHAT_EVENTSPAWNNPC_COMMAND.md)。

`HideCommand` / `PlayerVisibilityState` / `PlayerVisibilityService` 管理在线地图隐身，
集中完整实体和增量过滤，并接入移动、换图、跟随、换装、PvP 地图状态和附近交互目标校验。
数据库和客户端不变，详见 [管理员隐身](CHAT_HIDE_COMMAND.md)。
