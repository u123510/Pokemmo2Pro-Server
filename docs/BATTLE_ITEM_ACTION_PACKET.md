# 战斗道具动作封包

客户端使用 S2C `0x39` 在战斗内展示已选中道具的目标动作。它与普通背包道具销毁的 C2S `0x39`
共享 opcode，但由数据流区分，二者可以同时注册。

## 封包编号

```text
flow: SERVER_TO_CLIENT
opcode: 0x39 (十进制 57)
```

客户端参考实现为 `28887-obf-project/build/recompile/src/f/lh_2.java`，随后构造 `q80` 战斗事件。
目标存在时，客户端会把 `items/item_use` 粒子动作排入战斗事件队列。

## 数据结构

| 偏移 | 长度 | 字段 | 当前捕获取值 |
| ---: | ---: | --- | --- |
| `0x00` | 1 | 使用者阵营索引 | 行动宝可梦的 faction |
| `0x01` | 1 | 使用者登场槽位 | 行动宝可梦的 debut index |
| `0x02` | 2 | 道具索引 ID，LE | 捕获球 `itemIndexId` |
| `0x04` | 1 | 道具动作状态 | `0`，普通动作 |
| `0x05` | 2 | 目标名称后备本地化 ID，LE | `0`，目标对象存在时不会使用 |
| `0x07` | 可变 | UTF-16BE NUL 结尾的目标名称后备文本 | 空字符串 |
| 可变 | 1 | 目标数量 | `1` |
| 可变 | 8 | 目标宝可梦 Object ID，LE | 当前野生宝可梦 ID |
| 可变 | 2 | 目标标记，LE | `0` |
| 可变 | 1 | 嵌套战斗效果数量 | `0` |

`0x39` 的目标条目后可以继续附加与 S2C `0x33` 相同的战斗效果对象。该封包只适用于普通
战斗道具目标动作；野生捕获必须使用专用 S2C `0x37`，见 [`BATTLE_CAPTURE_PACKET.md`](BATTLE_CAPTURE_PACKET.md)。

## 普通道具顺序

```text
C2S 0x32 选择普通战斗道具
  -> S2C 0x39 战斗道具动作
  -> S2C 0x33/0x38 其他战斗结果（按道具效果）
```

客户端按接收顺序将战斗事件入队。不要把捕获球发送为此包，否则客户端只会播放通用
`items/item_use`，不会播放抛球、摇晃次数或捕获成功演出。
